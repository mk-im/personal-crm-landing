# Макет лендинга «Личная CRM»

Одна статичная страница. Одно целевое действие — перейти в приложение по кнопке «Открыть приложение».

Стек: Astro + Tailwind CSS 4, без сервера и базы. Правила проекта — в `../CLAUDE.md`; при расхождении с этим файлом прав `CLAUDE.md`.

## Файлы

| Файл | Что это |
|---|---|
| `mobile.html` | Эталон мобильной версии, ширина 390 px |
| `desktop.html` | Эталон десктопной версии, ширина 1440 px |
| `archive/` | Отклонённые варианты дизайна. **Не использовать** |

Макеты — образец вида: размеры, цвета, отступы и разметку брать из них. Код макетов — не готовый код сайта: в нём фиксированная ширина и нет адаптива.

## Тексты

Дословно, без правок. Менять текст — только с согласия владельца. Источник — `../landing.md`.

- **title:** Личная CRM — люди, которых вы знаете
- **description:** Кто это, откуда знакомы, телефон, почта и о чём договорились. Заметка после разговора остаётся в карточке контакта.
- **Логотип:** Личная CRM
- **Заголовок (h1):** Не теряйте людей и контекст разговора
- **Подзаголовок:** Список тех, кого вы знаете лично: кто это, откуда знакомы, телефон, почта и о чём договорились.
- **Проблема:**
  - крупно: Имя лежит в телефоне, переписка — в мессенджере, а договорённость помните только вы.
  - обычным: Через месяц уже неясно, откуда вы знакомы и что обещали.
- **Решение:**
  - крупно: Личная CRM — карточки людей, которых вы знаете.
  - обычным: Открыли список, добавили контакт, после разговора дописали заметку. В карточке остаются телефон, почта, откуда знакомы и о чём договорились. Тот же адрес в другом браузере показывает те же контакты.
- **Выгода:**
  - крупно: Перед следующим разговором карточка уже напоминает, кто этот человек и о чём вы договорились.
  - обычным: Знакомства и контекст общения остаются в одном списке.
- **Кнопка (2 раза: первый экран и конец страницы):** Открыть приложение

Подписи внутри иллюстраций («Контакты», «Заметка», «Сохранено», «Телефон», «Почта», «Откуда знакомы», «О чём договорились», «Карточка») и примеры данных (Анна Морозова, Игорь Левин, Мария Седова, «Митап по дизайну», «Друг брата», «Соседка по даче», «Договорились созвониться в пятницу», `+7 900 000-00-00`, `anna@mail.ru`, «+996») — часть картинки. Переносить как в макете. Блоки-иллюстрации помечать `aria-hidden="true"`.

## Кнопка

- Ссылка `<a>`, адрес — `https://crm.space`. Домен вынести в одну переменную окружения `PUBLIC_APP_URL` (в `.env`, пример — в `.env.example`).
- Открывать в той же вкладке.
- Других ссылок и кнопок на странице нет. Логотип — не ссылка.
- Hover: фон `#1A1A1A`, квадрат со стрелкой сдвигается на 2 px вправо-вверх. Focus: видимое кольцо `2px` цвета `--color-sky` с отступом `3px`.

## Дизайн-токены

Цвета, шрифты, радиусы и тени — только через `src/styles/tokens.css` (правило из `CLAUDE.md`). Готовое содержимое для Tailwind 4:

```css
@theme {
  --color-blue-1: #1454FC;   /* основной синий, акцент, аватары */
  --color-blue-2: #0432DF;   /* низ градиента, аватары */
  --color-blue-3: #5B9BF5;   /* блик в градиенте, аватары */
  --color-blue-deep: #0A2BC0;/* самый низ градиента */
  --color-sky: #AFD1F5;      /* пунктир, светлые аватары, фокус */
  --color-mist: #E4EFFB;     /* фон страницы, плашки внутри карточек */
  --color-note: #EAF1FF;     /* поле-акцент в карточке */
  --color-note-line: #C9DAFE;
  --color-ink: #0B1220;      /* основной текст на светлом */
  --color-muted: #5A6785;    /* второстепенный текст на светлом */
  --color-label: #6B7893;    /* подписи в карточках */
  --color-line: #D3DFF2;     /* полоски-заглушки текста */
  --color-divider: #E6ECF7;  /* разделители в карточках */
  --color-green: #2BD576;    /* галочка «сохранено» */
  --color-black: #000000;    /* кнопка */

  --font-sans: "Manrope", sans-serif;

  --radius-chip: 999px;
  --radius-btn: 14px;        /* десктоп 16px, финальная кнопка 16 / 18px */
  --radius-btn-icon: 10px;   /* десктоп 12px */
  --radius-card: 22px;       /* десктоп 26px */
  --radius-block: 32px;      /* синие блоки; десктоп 44px */

  --shadow-glass: 0 24px 50px rgba(2, 20, 120, .35);  /* карточки на синем первом экране */
  --shadow-card: 0 16px 36px rgba(4, 50, 223, .10);   /* карточки на светлом фоне */
  --shadow-step: 0 6px 16px rgba(20, 84, 252, .12);

```

Градиент синих блоков (первый экран, «Решение», финал):

```css
background:
  radial-gradient(120% 60% at 50% 0%, #5B9BF5 0%, rgba(91,155,245,0) 60%),
  linear-gradient(180deg, #1454FC 0%, #0432DF 70%, #0A2BC0 100%);
```

Белый на синем: основной `#FFFFFF`, второстепенный `rgba(255,255,255,.82)`. Стеклянные плашки на синем: фон `rgba(255,255,255,.16)`, рамка `1px rgba(255,255,255,.28–.3)`, `backdrop-filter: blur(10px)`. Карточки на синем: фон `rgba(255,255,255,.92)`.

## Адаптив

- **< 1024 px — мобильная раскладка** (`mobile.html`). Боковые отступы 20 px. На ширине больше 390 px контент не растягивать шире 600 px, центрировать.
- **≥ 1024 px — десктопная раскладка** (`desktop.html`). Контейнер 1200 px (в «Решении» 1120 px), по центру. Синие блоки «Решение» и финал — с отступом 40 px от краёв окна.
- Минимальная ширина — 360 px: ничего не обрезается, нет горизонтальной прокрутки.

## Экраны и блоки по порядку

### 1. Первый экран

Синий градиент, весь текст по центру. Мобильный — высота 844 px, десктоп — 920 px; на сайте — `min-height: 100svh`, но не меньше высоты контента.

Сверху вниз: стеклянная плашка-логотип (квадрат с кругом + «Личная CRM») → h1 → подзаголовок → чёрная кнопка с белым квадратом и стрелкой ↗.

Иллюстрация прижата к низу экрана, обрезается его краем:
- мобильный: белая карточка «Контакты» (2 человека + заметка), над её левым углом — плашка «Сохранено» с зелёной галочкой, повёрнута на −4°;
- десктоп: карточка «Контакты» 660 px по центру (3 человека); слева карточка «Карточка» с телефоном и почтой (−5°), справа карточка с заметкой (+4°), плашка «Сохранено» у левого верхнего угла.

### 2. Проблема (01)

Светлый фон `mist`. Номер 01 → крупный текст → обычный текст → иллюстрация: три белые карточки вразброс (телефон, переписка, синий квадрат с «?») вокруг пунктирного овала. Повороты −5°, +4°, −2°.
Десктоп: две колонки, текст слева, иллюстрация справа.

### 3. Решение (02)

Синий блок со скруглёнными углами. Номер 02 — стеклянная плашка. Крупный и обычный текст белые. Иллюстрация: белая карточка контакта (аватар, имя, зелёная галочка; поля «Телефон», «Почта» в две колонки; «Откуда знакомы», «О чём договорились» на всю ширину, выделены) и под ней два стеклянных окошка-«браузера» — те же контакты в другом браузере.
Десктоп: текст слева, иллюстрация справа.

### 4. Выгода (03)

Светлый фон. Номер 03 → крупный текст → обычный текст → иллюстрация: карточка «Анна Морозова» с заметкой и чёрным квадратом-карандашом в правом верхнем углу (+8°); ниже полоса из 4 аватаров внахлёст и плашки «+996».
Десктоп: иллюстрация слева, текст справа.

Не использовать колокольчик и другие намёки на уведомления — их в продукте нет.

### 5. Финал — призыв к действию

Синий блок, по центру. Тонкие концентрические кольца сверху (`rgba(255,255,255,.2)`), три аватара внахлёст с белой обводкой, кнопка «Открыть приложение» (мобильный — на всю ширину блока, десктоп — 440 px; текст слева, квадрат со стрелкой справа), внизу стеклянная плашка-логотип.

## Иконки

Инлайн-SVG, `stroke="currentColor"`, `stroke-width="2"`, скругления `round`, viewBox 24. Пути — в макетах: телефон, облачко переписки, карандаш. Стрелка в кнопке — символ ↗, галочка — ✓.

## SEO и мета

- `<html lang="ru">`, `title` и `meta description` — из раздела «Тексты».
- Один `h1` на странице.
- Open Graph (`og:title`, `og:description`) — те же тексты.

## Проверка готовности

- Страница совпадает с `mobile.html` на 390 px и с `desktop.html` на 1440 px.
- На 360, 768, 1024, 1280 px нет горизонтальной прокрутки и наложений.
- Обе кнопки ведут на `PUBLIC_APP_URL`.
- Все тексты совпадают с разделом «Тексты» символ в символ (включая «ё» и длинное тире «—»).
- Цвета и шрифт заданы только через `src/styles/tokens.css`.
- `pnpm build` проходит, `dist/` — статичные файлы.

## Открытые вопросы — уточнить у владельца, не решать молча

1. Домен приложения для `PUBLIC_APP_URL`.
2. Шрифт: Google Fonts (как в макете) или файлы шрифта в проекте (нужен пакет `@fontsource/manrope` — новая библиотека, согласовать).
3. Favicon и картинка для соцсетей (`og:image`) — пока нет.
